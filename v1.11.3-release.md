# Space Conquest v1.11.3

## Gameplay update
- Space flight uses keyboard movement without mouse camera control: W/S forward and backward, A/D left and right.
- Conveyor belts are intended to connect directly between machine output and machine input ports.
- Shipyard construction is intended to visibly progress in real time, with ship components being assembled as the build timer advances.

## Release
This file marks the v1.11.3 release request and documents the planned gameplay changes.
